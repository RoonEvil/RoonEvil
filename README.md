# About Me 👋

เว็บแนะนำตัวแบบมีเคอร์เซอร์ของหลายคน (Mint, Bank, Ploy) วิ่งมาคลิก แปะโน้ต แล้วพิมพ์ข้อมูลลงไปทีละตัวอักษร

- คนที่เข้ามาดูคลิกที่ว่างเพื่อทิ้งข้อความของตัวเองได้
- ลากโน้ตย้ายตำแหน่งได้
- กด "↻ เล่นใหม่" เพื่อเล่นแอนิเมชันอีกรอบ

## แก้ข้อมูล (ตอนนี้เป็นตัวละครสมมติ "ภูมิ ใจดีมาก")
เปิด `index.html` แล้วแก้ `NOTES` (ข้อความ, สี, ตำแหน่ง) และ `CURSORS` (ชื่อ/สีของเคอร์เซอร์) ด้านบนสุดของ `<script>`

## ขึ้นเว็บด้วย GitHub Pages
Settings → Pages → Source: Deploy from a branch → เลือก branch แล้วเลือก `/ (root)`
