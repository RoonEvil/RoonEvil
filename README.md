# ภูมิ — Portfolio (showcase)

เว็บโปรไฟล์ตัวอย่าง (ข้อมูลสมมติทั้งหมด) ที่ทำเหมือนหน้าจอ Figma มีทีม 10 คนช่วยกันออกแบบสดๆ:
วาดกล่อง ลงสี พิมพ์ข้อความ ลากของ ปรับ progress bar คอมเมนต์ และแชตผ่านเคอร์เซอร์

- 9 ส่วน: Hero, About, Skills, Projects, Journey, Numbers, Moodboard, Team says, Contact
- **Auto tour** เลื่อนจอตามงานให้เอง ถ้าเลื่อนเองจะหยุด auto ให้ กดปุ่มเพื่อเปิดอีกครั้ง
- มี Layers panel / Design panel / Activity แบบ Figma บนจอใหญ่

แก้ข้อความได้ใน HTML ส่วน `<main id="canvas">` และแก้ลำดับแอนิเมชันได้ที่ `SCRIPTS` ใน `<script>`

ขึ้นเว็บ: Settings → Pages → Deploy from a branch → `/ (root)`
